### nedit

nedit is VERY similar to ncat, but instead of listing the contents of a PATH command's file, it lets you edit it using Helix.

### Usage

- `nedit [file]` - Edit a file.
- `nedit [PATH command]` - Edit the file of a PATH command.
- `nedit help/--help/-h` - Show the CLI help menu.
- `nedit packages` - Edit your nup package list.

### Compatibility

Uses Helix for now. Since the tool is really simple, you can edit it yourself to match your text editor if you wish.
