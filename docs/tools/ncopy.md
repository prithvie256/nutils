### ncopy

ncopy is a Bash tool that takes the output of a command and copies it with `wl-copy`.

### Usage

- `ncopy [command]` - copy the output of a command.
- `ncopy help/--help/-h` - show the CLI help menu.

### Compatibility

Will work on any Wayland system. Sorry to the people over at X11 because I haven't added support for you guys yet!
