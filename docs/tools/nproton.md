### nproton

nproton is LITERALLY just the process of running Proton standalone in ngame ripped out into its own minimal script.

### Usage

- `nproton [windows exe]` - Run a Windows executable.
- `nproton [wine/proton command]` - Run a Wine/Proton process with Proton.
- `nproton help/--help/-h` - Show the CLI help menu.

### Compatibility

Any Linux system with Steam, Steam Linux Runtime 4 and Proton Experimental installed will be able to run this.
